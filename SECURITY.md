# Security Policy

## Supported Versions

Only the latest deployed version on the `master` branch (`https://peakloads.com/`) receives security updates.

| Version | Supported |
| ------- | --------- |
| `master` (latest) | :white_check_mark: |
| Older commits | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in PeakLoads, please **do not** open a public GitHub issue.

Instead, report it privately using one of the following methods:

1. **GitHub Private Vulnerability Reporting (Preferred):** Go to the [Security Advisories](https://github.com/TheCrimsonborn/PeakLoads/security/advisories/new) page and submit a private report.
2. **Direct Contact:** Reach out to the maintainer via the profile links listed on [peakloads.com](https://peakloads.com/).

Please include:
- A clear description of the vulnerability and its potential impact.
- Steps to reproduce or a proof-of-concept.
- Affected files, endpoints, or browser environments.

We will acknowledge your report within **72 hours** and aim to provide a fix or mitigation plan as quickly as possible.
